Estonian Holidays

A calendar subscription for Estonian public holidays and shortened work days. Calculated locally using official government rules - no external dependencies!

📥 Download Calendar

📅 What's included?

  • 🎉 Public holidays (Riigipüha & Rahvuspüha) - official days off
  • ⏰ Shortened work days (Lühendatud tööpäev) - days when workday ends earlier

🔗 How to subscribe?

Option 1: Direct download

Click the download button above and import the .ics file into your calendar app.

Option 2: Subscribe (auto-updates)

Use this URL in your calendar app to get automatic updates:

https://shintotuna.github.io/ee-holiday-calendar/estonian-holidays.ics

📱 How to add to your calendar?

  • Apple Calendar: File → New Calendar Subscription → Paste URL
  • Google Calendar: Settings → Add calendar → From URL → Paste URL
  • Outlook: Calendar → Add calendar → Subscribe from web → Paste URL

🧮 Calculated locally using Estonian government holiday rules

📅 Easter dates calculated using Gregorian Computus algorithm
